# VELOOP Rewards: Banner Redesign (Task 08)

## Live Demo

**[View the live VELOOP Rewards website](https://veloop-rewards-banner-redesign-ten.vercel.app/)**

## Project Overview

Five premium, fintech-style promotional banners for the VELOOP Rewards platform, built as a reusable React banner system. Page background is `#161827`.

## Banner List

| # | Banner | Route | Visual idea |
|---|---|---|---|
| 1 | Refer & Earn | `/refer-earn` | Friends, gift box and referral code |
| 2 | Swap Center | `/swap-center` | VE and SVE reward currency conversion |
| 3 | Bonus VEs | `/bonus-ves` | Activities feeding a bonus meter |
| 4 | Captcha Tasks | `/captcha-tasks` | Captcha task experience |
| 5 | Exchange Center | `/exchange-center` | Gem-to-VE exchange concept |

## Features

- Reusable `RewardBanner` shell with five distinct banner designs
- Copy-to-clipboard referral code and animated reward counters
- Responsive layouts and accessible interactive controls
- Reduced-motion support and off-screen animation handling

## Technology Stack

React, Vite, Bootstrap 5, CSS Modules, React Hooks, React Router, Lucide React and React Icons.

## Installation

npm run dev
